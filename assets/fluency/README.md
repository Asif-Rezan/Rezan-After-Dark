# Approved visual assets

Original artwork generated with the built-in image_gen tool in this project conversation. No model or image API is called during daily rendering.

- `conversation-characters.png`: original male/female 3D storybook art. Prompt: pure white background, friendly adult male in teal overshirt far left, friendly adult female in mustard cardigan and dark headphones far right, inward-facing gestures, blank central half for subtitles, complete hands, no text/logos.
- `approved-thumbnail.png`: approved reference with angled black condensed display lettering, white outlines, hard black shadow and yellow background. Reference only, never uploaded as a shared daily thumbnail.
- `emma-thumbnail.png`: reusable transparent cutout. Prompt: preserve the approved adult female identity, chestnut hair, dark headphones, mustard cardigan, white top, jeans; one hand waving near shoulder and the other resting in front of waist, both complete arms and all fingers inside frame; no text or background; clean transparent alpha. Isolated artwork prevents the cropped hand defect.
- `Anton-Regular.ttf` and `NotoSans.ttf`: bundled Google Fonts, under their included SIL Open Font Licenses. Used for consistent offline rendering on macOS and Linux.

Every lesson gets a new thumbnail file: a generated topic-specific headline, seeded stack angle, exact #FFFF00 background, code-rendered text and the reusable complete character. The host identity intentionally stays consistent.
