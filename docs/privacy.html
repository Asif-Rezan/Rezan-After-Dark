Rezan After Dark Automation privacy policy

Last updated: November 10, 2026

Rezan After Dark Automation is operated by Asif Rezan for the Rezan After Dark YouTube channel. It is an owner-operated video creation and upload workflow, not a public service with user accounts.

Google data accessed

With the operator's Google authorization, the workflow reads the selected YouTube channel's identity and video information, uploads videos, metadata, thumbnails, and English caption tracks to that channel, and accesses files in an app-authorized Google Drive folder used for video production. The requested permissions are YouTube read and upload access and Google Drive access limited to files used with this app.

Use and storage

The workflow uses this information only to prepare, store, upload, and verify the operator's videos. OAuth credentials are stored as encrypted GitHub Actions secrets. Production files and checkpoints are stored in the operator's Google Drive. Daily lesson text and synthetic narration are generated locally on the runner using downloaded Qwen and Kokoro models. The optional local preview can send lesson text to the Edge speech service. Google OAuth credentials are not sent to generation providers.

Sharing and retention

Google data is not sold or used for advertising. It is shared only with the services needed to run this workflow, including Google Drive, YouTube, and GitHub Actions. After successful private-video verification, disposable run media is deleted using a checked file manifest. Essential lesson records and recovery checkpoints are retained until the operator deletes them. Failed or ambiguous uploads retain assets for recovery. The operator can revoke the app's Google access and delete stored credentials and files at any time.
